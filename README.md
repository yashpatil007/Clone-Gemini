# Gemini Clone Application

This project is a clone of the Gemini platform, developed using React.js and integrated with live APIs to fetch and display real-time cryptocurrency data. The application allows users to track cryptocurrency prices, view asset details, and interact with real-time data from a dynamic API.

## Features

- **Real-time Data**: Fetches real-time cryptocurrency data using live APIs.
- **Asset Tracking**: Users can track and view details of various cryptocurrencies.
- **Interactive UI**: Developed with React.js to ensure a responsive and interactive user experience.
- **Real-time Updates**: The application continuously updates cryptocurrency prices in real-time, giving users the latest information.
- **Responsive Design**: The front-end is built using HTML, CSS, JavaScript, and React.js for a responsive and mobile-friendly design.

## Tech Stack

- **Frontend:**
  - React.js
  - HTML, CSS, JavaScript
  - Bootstrap

- **APIs:**
  - Live APIs (for real-time cryptocurrency data)

- **Tools:**
  - Git
  - GitHub
  - VS Code
